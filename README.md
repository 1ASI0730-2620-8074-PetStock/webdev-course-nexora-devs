# Curso de Fundamentos de Desarrollo Web (HTML & CSS)

Repositorio oficial del curso introductorio de desarrollo web dirigido a estudiantes de secundaria.

---

## Estructura del Repositorio

El repositorio está organizado de la siguiente manera para facilitar el aprendizaje autónomo de los estudiantes:

* `/starter-files`: Contiene los archivos base o iniciales de código para que los estudiantes comiencen cada lección.
* `/completed-examples`: Contiene los ejemplos completos y resueltos de cada lección para referencia y validación de resultados.
* `/scripts`: Contiene los guiones y el contenido detallado en formato Markdown para la grabación de los videos de cada lección.
* `course-plan.md`: Documento principal con la ruta de aprendizaje completa, enlaces a los videos de YouTube, cuestionarios y accesos directos a los editores en línea.

---

## Instrucciones de Uso

1. **Videos del Curso:** Accede a la secuencia completa de lecciones mediante los enlaces proporcionados en el archivo `course-plan.md`. Todos los videos están alojados en YouTube como contenido no listado.
2. **Prácticas en Línea:** No se requiere la instalación de software local. Todo el código se ejecuta directamente en editores web gratuitos y accesibles desde el navegador como **CodePen**.
3. **Revisión de Código:** Los estudiantes y docentes pueden consultar el código de inicio en la carpeta `/starter-files` y el resultado final de referencia en `/completed-examples` de cada lección correspondiente.

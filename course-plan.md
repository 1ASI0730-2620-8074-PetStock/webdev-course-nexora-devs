

## Resumen del Curso
Este curso introductorio de aproximadamente 1 hora está diseñado para enseñar a estudiantes de secundaria a crear sus propias páginas web desde cero utilizando HTML y CSS.

**¡No requiere descargas!** Todo el entorno de desarrollo es 100% en línea y gratuito. Solo necesitas tu navegador web.

* **Duración total**: ~60 minutos
* **Público objetivo**: Estudiantes de 12 a 17 años sin experiencia previa en programación
* **Prerrequisitos**: Ninguno
* **Herramientas necesarias**: ¡Solo tu navegador web! (Chrome, Firefox, Safari, Edge)
* **Editor en línea**: [CodePen](https://codepen.io)
* **Repositorio de código fuente**: [https://github.com/1ASI0730-2620-8074-PetStock/webdev-course-nexora-devs](https://github.com/1ASI0730-2620-8074-PetStock/webdev-course-nexora-devs)

## Secuencia de Lecciones

### Módulo A: Conociendo la web

#### Lección 1: ¿Qué es el desarrollo web? (Pendiente)
* **Descripción**: Descubre qué hay detrás de tus páginas favoritas como Roblox o Pinterest, cómo funciona un navegador y por qué HTML y CSS son el dúo dinámico de internet.
* **Video**:  [Ver la lección](https://youtu.be/ukjamPdrOsk?si=lcS4IvlDB0Y-QDRl)
* **Consejos clave**: Todo sitio web combina Contenido (HTML) y Estilo (CSS). ¡No necesitas instalar nada, solo abrir tu navegador y empezar!
* **Práctica**: [ Explora tu primer codigo en CodePen](https://codepen.io/desarollador/pen/qErvbVp?editors=1100)

#### Lección 2: Tu primera página HTML (Pendiente)
* **Descripción**: Todo sitio web tiene un esqueleto oculto bajo la pantalla. Descubre cómo armarlo pieza por pieza con tus primeras etiquetas HTML y dale forma a tu propia página de presentación en minutos.
* **Video**: [Ver la lección](https://youtu.be/RI4IYNBt8JQ?si=rBeYyQDxVX_NlCkT)
* **Consejos clave**: ¡No olvides cerrar tus etiquetas! Usa siempre un único h1 por página como título principal y organiza tus subtítulos de forma ordenada (h2, h3, etc.).
* **Práctica**: [Crea tu primera estructura en CodePen](https://codepen.io/desarollador/pen/PwpLzwm?editors=1100)

### Módulo B: Organizando el contenido HTML

#### Lección 3: Dando formato al texto (5 minutos)
* **Descripción**: Ayuda a Lucía a darle formato a su página personal: destaca palabras, sepáralas con una línea y corta los versos de una adivinanza.
* **Video**: [Ver la lección](https://youtu.be/_tl326nUC5Y)
* **Consejos clave**: Usa `<strong>` (negrita), `<em>` (cursiva) y `<mark>` (resaltado); `<hr>` y `<br>` no se cierran; al combinar etiquetas, ciérralas en orden inverso.
* **Práctica**: [Dale formato en CodePen](https://codepen.io/editor/aprende-html-web/pen/01a1ce51-ce89-7e44-94ce-6c9a518098f1?tab=%2Findex.html&orientation=left&panel=false&show=split)

#### Lección 4: Creación de listas (5 minutos)
* **Descripción**: Publica la receta de chocolate caliente de Lucía con una lista de ingredientes y una lista de pasos numerados.
* **Video**: [Ver la lección](https://youtu.be/ms2JkygFzpY)
* **Consejos clave**: Usa `<ul>` cuando el orden no importa y `<ol>` cuando sí importa; cada elemento va en un `<li>` y los números salen solos.
* **Práctica**: [Crea tus listas en CodePen](https://codepen.io/editor/aprende-html-web/pen/01a1ce65-6719-7c45-a572-1a3af7c0dcfd?tab=%2Findex.html&orientation=left&panel=false&show=split)

### Módulo C: Multimedia y navegación

#### Lección 5: Añadiendo imágenes (Pendiente)
* **Descripción**: Aprende a insertar imágenes en una página HTML utilizando la etiqueta `<img>` y los atributos `src`, `alt` y `width`.
* **Video**: [Ver la lección](https://youtu.be/A8QsOUjZ4Ck?si=WGsjsd0p0OTnmra0)
* **Consejos clave**: Usa `src` para indicar la ubicación de la imagen, `alt` para proporcionar una descripción alternativa y `width` para controlar su ancho. Verifica que la dirección de la imagen sea correcta y utiliza textos alternativos descriptivos.
* **Práctica**: [Agrega tus imagenes en CodePen](https://codepen.io/desarrolloweb56/pen/rayRpJW?editors=1000)

#### Lección 6: Conectando la web con enlaces (Pendiente)
* **Descripción**: Aprende a crear enlaces en HTML para conectar tu página con otros sitios y recursos utilizando la etiqueta `<a>` y el atributo `href`.
* **Video**: [Ver la lección](https://youtu.be/wWvV-5NRWNs?si=IgT6aN60pFeTqI7B)
* **Consejos clave**: Usa `<a>` para crear enlaces, `href` para indicar el destino y un texto claro para el usuario. Puedes combinar los enlaces con `<ul>` y `<li>` para organizar varios recursos en una lista.
* **Práctica**: [Agrega tus enlaces en CodePen](https://codepen.io/desarrolloweb56/pen/ZYePvrO?editors=1000)

### Módulo E: Proyecto final y revisión
#### Lección 9: Creando tu página de perfil (5 minutos)
* **Descripción**: Combina todo lo aprendido para crear tu propia tarjeta de perfil con foto, nombre, pasatiempos y un botón, usando HTML y CSS.
* **Video**: [Ver la lección](https://youtu.be/Sq7geX_w4jA)
* **Consejos clave**: Usa clases (`class="foto"` en HTML y `.foto` en CSS) y `border-radius: 50%` para una foto redonda.
* **Práctica**: [Crea tu perfil en CodePen](https://codepen.io/Nexora-Web-cu/pen/dPGBPQG)

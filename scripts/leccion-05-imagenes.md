
# Lección 05: Cómo insertar imágenes en HTML

## Duración
6 minutos aproximadamente.

## Objetivo
Aprender a mostrar imágenes en una página web utilizando la etiqueta `img` y sus atributos principales.

## 1. Introducción (1 minuto)

En las lecciones anteriores construimos una página con texto y listas. Ahora vamos a agregar imágenes para que el contenido sea más visual.

Por ejemplo, una página sobre animales puede mostrar fotografías de gatos y perros.

## 2. La etiqueta img (2 minutos)

En HTML usamos la etiqueta `img` para mostrar una imagen.

Escribimos la dirección de la imagen en el atributo `src`:

```html
<img src="URL_DE_LA_IMAGEN" alt="Un gato sentado">
```

`src` indica dónde está la imagen.

`alt` ofrece una descripción si la imagen no se carga y ayuda a las personas que utilizan lectores de pantalla.

La etiqueta `img` no necesita una etiqueta de cierre.

## 3. Tamaño y descripción (1 minuto)

Podemos indicar un ancho con `width`:

```html
<img src="gato.jpg" alt="Gato mirando a la cámara" width="300">
```

Usa una descripción breve y útil en `alt`; no escribas simplemente "imagen".

En una práctica en línea, puedes utilizar una URL pública de una imagen.

## 4. Actividad práctica (1 minuto)

Abre el archivo inicial en un editor en línea.

Añade una imagen de tu animal favorito, escribe un `alt` descriptivo y ajusta el ancho.

Luego agrega una segunda imagen.

## 5. Cierre (1 minuto)

Hoy aprendimos a insertar imágenes con `img`, `src`, `alt` y `width`.

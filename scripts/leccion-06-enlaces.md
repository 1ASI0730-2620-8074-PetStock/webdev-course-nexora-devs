
# Lección 06: Crear enlaces en HTML

## Duración
6 minutos aproximadamente.

## Objetivo
Aprender a crear enlaces para navegar a otras páginas o recursos de Internet.

## 1. Introducción (1 minuto)

Los enlaces conectan páginas y permiten acceder a información relacionada.

Por ejemplo, desde una página sobre animales podemos enlazar una guía para aprender más.

## 2. La etiqueta a y el atributo href (2 minutos)

Para crear un enlace utilizamos la etiqueta `a`.

El atributo `href` contiene la dirección de destino:

```html
<a href="https://developer.mozilla.org/">Aprender desarrollo web</a>
```

El texto que aparece entre las etiquetas es el texto que la persona puede seleccionar.

La dirección se escribe en `href`.

## 3. Enlaces en una lista (1 minuto)

Podemos organizar varios recursos en una lista:

```html
<ul>
  <li><a href="https://www.w3schools.com/html/">Tutorial de HTML</a></li>
  <li><a href="https://codepen.io/">Editor en línea</a></li>
</ul>
```

Así agrupamos enlaces relacionados y facilitamos su lectura.

## 4. Actividad práctica (1 minuto)

En el editor en línea, crea dos enlaces a recursos educativos que conozcas.

Comprueba que cada dirección esté bien escrita y que el texto explique a dónde lleva el enlace.

## 5. Cierre (1 minuto)

Hoy aprendimos a usar `a` y `href` para crear enlaces.

Ya sabemos añadir texto, listas, imágenes y enlaces a nuestra página.

Más adelante aprenderemos cómo cambiar su apariencia con CSS.

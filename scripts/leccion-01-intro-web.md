## ¿Qué es un sitio web? 

Un sitio web es un conjunto de páginas conectadas entre sí, que puedes abrir desde tu navegador. Roblox, Canva y Pinterest son sitios web.

Cuando escribes una dirección, tu navegador la pide por internet a una computadora llamada servidor, y esa computadora le envía la página. En segundos, la ves en tu pantalla.

El desarrollo web es el trabajo de crear esas páginas, y quien lo hace se llama desarrollador web.

## Los dos lenguajes fundamentales: HTML y CSS 

Las páginas web se construyen con varias tecnologías, pero hay dos lenguajes que son los fundamentales, la base de todo: HTML y CSS. Si los aprendes bien, tendrás los cimientos para seguir aprendiendo más adelante.

El HTML se encarga del contenido: los títulos, los textos, las imágenes y los enlaces. Sin HTML, no habría nada que mostrar.

El CSS se encarga del estilo: los colores, las letras, los tamaños y los espacios. Sin CSS, la página funciona, pero se ve muy simple.

Piénsalo como el menú de un restaurante. El HTML son los platos y los precios, o sea, la información. El CSS es el diseño del menú: sus colores, sus letras y cómo está ordenado. La información es la misma, pero cambia por completo cómo se ve.

## ¿Qué es un navegador web? 

El navegador web es el programa que recibe el HTML y el CSS y los convierte en la página que ves en pantalla. Los más conocidos son Chrome, Firefox, Safari y Edge. Seguramente ya usas uno todos los días

## ¿Qué necesitas para empezar? 

En este curso no necesitas instalar nada. Solo necesitas dos cosas: un navegador web y conexión a internet.

Para practicar usaremos CodePen, una herramienta gratuita en línea. Tiene un panel para escribir HTML, otro para CSS y un resultado que se actualiza al instante. No necesitas crear una cuenta. En la descripción de cada video encontrarás el enlace para abrir el ejercicio.

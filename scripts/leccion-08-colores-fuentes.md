
# Lección 08: Colores, fuentes y alineación

## Duración
6 minutos aproximadamente.

## Objetivo
Aprender a modificar colores, tamaños de letra,
alineaciones, bordes y espacios utilizando CSS.

## 1. Introducción (1 minuto)

En la lección anterior aprendimos a utilizar CSS.

Ahora continuaremos trabajando en nuestra página
para mejorar su apariencia.

Aprenderemos a cambiar el tamaño del texto,
alinear contenido y agregar bordes.

## 2. Fuentes y tamaños (1 minuto)

La propiedad font-family permite elegir
el tipo de letra.

Ejemplo:

    body {
        font-family: Arial, sans-serif;
    }

La propiedad font-size permite cambiar
el tamaño del texto.

Ejemplo:

    h1 {
        font-size: 32px;
    }

## 3. Alineación del contenido (1 minuto)

La propiedad text-align permite alinear el texto.

Ejemplo:

    body {
        text-align: center;
    }

Podemos utilizar los valores left, center
o right según cómo queramos alinear el texto.

## 4. Bordes y espacios (1 minuto)

La propiedad border permite colocar
un borde alrededor de un elemento.

Ejemplo:

    h1 {
        border: 2px solid darkblue;
    }

La propiedad padding permite agregar
espacio entre el contenido y su borde.

Ejemplo:

    h1 {
        padding: 10px;
    }

## 5. Actividad práctica (1 minuto)

Continuamos utilizando nuestra página
de la lección anterior en CodePen.

Ahora agregaremos las propiedades:

- font-size
- text-align
- background-color
- border
- padding

Comparamos la apariencia inicial
con el resultado terminado.

## 6. Conclusión (1 minuto)

Hoy aprendimos a modificar el diseño de
nuestra página utilizando CSS.

Ahora conocemos varias propiedades que
nos permiten mejorar la apariencia de
nuestros sitios web.

En la siguiente lección utilizaremos
estos conocimientos para crear una página
de perfil personal.
